# Phytosense AI - Frontend Workspace 🖥️

This directory contains the user interface for the **Phytosense AI** diagnostic system. It is a Human-Centric Explainable AI (HXAI) dashboard built to run smoothly in the browser, featuring a state-driven, reactive UI and deep dark-mode aesthetics.

## 🛠 Tech Stack

*   **Framework:** [Next.js](https://nextjs.org/) (App Router)
*   **Styling:** [Tailwind CSS](https://tailwindcss.com/)
*   **Animations & Physics:** [Framer Motion](https://www.framer.com/motion/)
*   **Icons:** [Lucide React](https://lucide.dev/)

## 🚀 Quick Start

To run the interactive UI prototype locally on your machine:

1. **Install dependencies:**
   ```bash
   npm install

2. **Run the dev server:**
   ```bash
   npm run dev
